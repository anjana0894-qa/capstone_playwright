# Playwright Automation Framework

Simple Playwright JavaScript framework for UI automation.

### Includes

* Playwright with JavaScript
* Page Object Model (POM)
* Reusable helpers
* JSON/Excel test data
* Playwright reports
* GitHub Actions CI

### Structure

```text
project/
├── pages/
├── tests/
├── helpers/
├── testData/
├── .github/
│   └── workflows/
├── playwright.config.js
└── package.json
```

### Flow

```text
Test → Page Object → Helper/Test Data → Playwright → Report
```
